# 关于IOTO启动库
IOTO启动库是为了让Obsidian新手能快速使用Obsidian和IOTO而准备的一个极简库。

## 文件和文件夹
- 只有一个README文件
- 没有预设文件夹
- 在部署IOTO的过程中会自动创建相关的文件夹

## 主题
- 预装并启用了`AnuPPuccin`主题
- IOTO可以在任何主题下使用，`AnuPPuccin`主题只是Johnny个人使用了多年的主题，可以根据自己的需求切换其他主题

## 插件
- 预装`Templater`插件
	- `Templater`插件是IOTO框架在正常使用过程中唯一依赖的第三方插件
	- 在使用的过程中，你可以不去对`Templater`插件进行任何的设置，IOTO在部署的过程中，会自动完成相关设置
- 预装`Style Settings`插件
	- `Style Settings`插件是为了对`AnuPPuccin`主题，进行一些个性化设置
	- 当前启动库，已经加载了Johnny平时使用的主要自定义配置
- 预装`IOTO Update`插件
	- `IOTO Update`插件是部署IOTO框架，以及安装IOTO辅助插件的中枢插件
	- IOTO是框架是付费产品，使用`IOTO Update`部署IOTO，需要先购买IOTO，然后使用Johnny提供的API key和购买时提供的邮箱，进行验证和部署。
